# 🚀 Featured Project

## 📚 AI Notes Studio

**AI Notes Studio** is an AI-powered learning application designed to help users understand and study PDF documents more effectively.

The application combines **PDF processing, AI assistance, interactive learning tools, chat history, diagrams, and customizable themes** in one workspace.

### ✨ Key Features

* 📄 **PDF Upload & Reading**
* 📝 **AI-Powered Summarization**
* ⭐ **Important Points Generation**
* ❓ **Quiz Generation**
* 🧠 **AI Learning Assistance**
* 💬 **AI Chat & Chat History**
* 📊 **Diagram Generation**
* 🔊 **Text-to-Speech**
* 🌙 **Dark & Light Themes**
* 📚 **Interactive Learning Workspace**
* 🔄 **Retry / Regenerate AI Results**
